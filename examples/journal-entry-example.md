# Source files before 2024 use abbreviated citation format

## Context
While preparing the source brief for Chapter 6, I encountered PDFs from the 2019-2023 period that use a different citation format than the post-2024 materials.

## Insight
Pre-2024 source files use abbreviated author-date citations (e.g., "K. 1987" instead of "Kandinsky 1987"). The abbreviation key is not included in the PDFs themselves — it appears in a separate reference document at `Source Materials/reference-keys/pre-2024-abbreviations.md`. Any extraction from pre-2024 sources must cross-reference this file to expand citations correctly.

## Applies when
- Working with any PDF source dated before 2024.
- Extracting or verifying citations from older materials.
- Preparing source briefs that span both pre- and post-2024 documents.
